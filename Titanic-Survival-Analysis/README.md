# 🚢 Titanic Survival Analysis

Analyzes the Titanic passenger dataset to explore the factors associated with
passenger survival. This beginner-level Data Science project focuses on
data understanding, data cleaning, exploratory data analysis (EDA),
statistical analysis, and data visualization.

The project explores how survival varied by gender, passenger class,
age, and number of siblings/spouses aboard.

---

## 📊 Dataset

- **Source**: Kaggle Titanic Dataset
- **Samples**: 891 passengers
- **Features**: `PassengerId`, `Pclass`, `Name`, `Sex`, `Age`, `SibSp`,
  `Parch`, `Ticket`, `Fare`, `Cabin`, `Embarked`, `AgeGroup`
- **Target**: `Survived`
  - `0` = Did not survive
  - `1` = Survived
